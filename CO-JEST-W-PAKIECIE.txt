✨ CO MOŻESZ ZROBIĆ:

1. Rozpakuj archiwum
2. Przeczytaj SZYBKI-START.md (albo README.md dla szczegółów)
3. Zainstaluj zależności: npm install (w backend i frontend)
4. Uruchom: npm start (w backend i frontend - dwa terminale)
5. Otwórz przeglądarkę: http://localhost:3000
